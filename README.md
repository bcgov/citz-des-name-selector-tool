## Name Selector Tool
---
BC Vital Statistics allow for longer names for their birth certificates, but Provincial government identifications (ID) have stricter limitations. This is a concern for people with traditional names where drivers license's and other forms of ID's will cut off the name or have issues with specific characters.

This application will serve users to validate that their names can fit within the ID or provide alternate spelling for traditional names and spelling.

## Features

- Support for mononym and polynym names
- Validate first, last, and up to two middle names
- Form for alternate spelling
